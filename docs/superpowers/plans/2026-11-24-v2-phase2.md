# Plan: Mnemo v2 Phase 2 ("decide on write"): branches and the G1 design note

## Context
Tom's spec is `docs/phase2-spec.md`, dated 2026-11-24 and currently untracked.

**Why Phase 2.** Tom reviewed the supersedes edges from Phase 1 and found that the legacy lifecycle detector hides atoms it shouldn't:
- a day's reading retired a baseline;
- notes about different days were treated as a state change.

**What Phase 2 changes.** A relation is decided on write: `same`, `replaces`, `refines`, `conflict` or `unrelated`.
- The decision is gated by a kind matrix (state, plan, observation, rule, unknown), by date precision, and by global guards.
- It runs on OpenRouter Decisions models with ZDR.
- It runs in shadow first, then enforce.

**Prerequisites, all met:**
- production runs `9b5776b`;
- PR #29 is merged (`927a27d`);
- `MNEMO_RECALL_HIDE_SUPERSEDED=false`.

**This plan covers work item 1 only:** create the branches and write `docs/phase2-design.md`, then **STOP at G1**. Under the spec, no feature code is written before Tom reviews the design note.
